# KYN-X Motion Editor V3

A browser-based mobile-first motion editor.

## V3 focus
- Import video/image/audio immediately
- Media library
- Real timeline clips
- Tap a clip to edit
- Trim start/end
- Split at playhead
- Duplicate/delete
- Transform controls
- Opacity/rotation/scale
- Keyframes with easing
- Speed control
- Frame stepping
- Timeline scrubbing
- Text overlays
- Canvas preview
- Project save/load
- Export moved out of the way

This is a browser editor. It does not pretend browser MediaRecorder is a professional AI interpolation/upscaling pipeline.
